# Character & prop prompts for Nano Banana

Goal: images that turn cleanly into 3D (Meshy / Tripo image-to-3D) and match the 3D section's art direction: **sunlit San Diego, earth tones, blue sky, low-poly stylized**. The 2D space game is neon and dark; this part is warm daylight.

## How to use
1. Generate each character's **turnaround sheet** first (prompt below). Keep the best one as the *reference image*.
2. For every later image of that character (poses, expressions, 3D input), upload the reference and say "same character as the reference image".
3. For 3D conversion, use the **single full-body A-pose** prompt: plain background, flat even lighting, no shadows, nothing cropped. Auto-rigging works best on humanoid A/T poses.
4. Faces of real people: describe the character, or upload your own photo as a reference if you want a likeness. I haven't written any real person's name into a prompt.

## Style block (paste at the start of every prompt)
```
Stylized low-poly 3D game character, clean flat-shaded shapes with soft color gradients,
chunky readable silhouette, slightly exaggerated proportions, warm earth-tone palette
(terracotta, adobe, cream, sage green, dusty blue, mustard), daylight look. Not photorealistic.
Neutral plain light-gray background, soft even lighting, no cast shadows.
```

## Turnaround sheet suffix
```
Character turnaround sheet: full body front view, side view and back view side by side,
same character, same proportions, A-pose, arms slightly away from the body, feet visible,
nothing cropped, consistent colors.
```

## Single full-body (for 3D) suffix
```
Single character, full body, front view, A-pose, centered, nothing cropped,
plain light-gray background, flat even lighting, no shadows, no props floating around.
```
