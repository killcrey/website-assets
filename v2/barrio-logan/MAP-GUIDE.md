# Barrio Logan map guide: how to draw the section for the game

Goal: turn the part of Barrio Logan that matters to you into a block layout I can build. A rough, honest drawing is enough; I will build a grey-box street from it and overlay it on your map so you can check it.

## 1. Pick the area
- About **3 blocks wide by 2 blocks tall (6 blocks)** to start. One neighbourhood at a time; we can add more later.
- Include the spot that means the most to you. Tell me which block is **Home Base** (where memories get banked).

## 2. Get the base image
- Google Maps in **satellite** view, flat top-down (no tilt), **north up**. Screenshot it. Zoom so the 6 blocks fill the screen.
- Optional: a second screenshot in street view of anything that matters (storefronts, the pillars, a mural). Your own phone photos are better.

## 3. Mark it up (any markup tool; phone Markup is fine)
Use these codes so I can read it quickly.

**Streets**
- Write each street's name along it. Arrow for one-way streets.
- Put a red dot on each **traffic light** and a white bar on each **crosswalk**.

**Blocks**
- Name each block A1, A2, A3 (top row), B1, B2, B3 (bottom row).

**Buildings**: draw a box for each, and write: type code + floors (1 to 3) + an arrow for which side the front door faces.

| Code | Meaning |
|---|---|
| T | taqueria / restaurant |
| P | panadería / bakery |
| M | mercado / corner market |
| A | auto shop / tire shop / garage |
| H | house (stucco, porch) |
| AP | apartment building |
| B | barbershop / salon / small shop |
| C | church / community hall |
| W | warehouse / workshop |
| V | vacant lot / dirt lot |
| PK | park |
| FW | freeway / bridge pillars |
| MU | wall with a mural (draw a line on the wall) |

**Extras**
- Alleys and gaps between buildings: mark them with a dashed line.
- Parking lots: shade in grey. Fences and walls: draw a thick line.
- Palm trees: a green dot. Street vendors / carts: a yellow dot.
- Landmarks: number them L1, L2, ... and name each in the notes (for example the park, the bridge, the pillars).

## 4. Send me
1. The clean screenshot and the marked-up one.
2. A short list: the street names, the block names (A1 ...), the landmarks (L1 ...), and which block is Home Base.
3. **6 to 10 photos** from the ground, each labelled with the block and building they show (for example "A2 taqueria front"). Your own photos are best.
4. Anything that must NOT change or must be exact, and anything that is only inspiration.

## 5. What I do with it
1. Convert it into block specs (position, size, height, front direction, style) in the game's data format.
2. Build a grey-box version (no art yet) and send you a top-down comparison so you can say "move this, make that taller".
3. Drop in the textures and models from Gemy and me, one block at a time.

## Scale and honesty rules
- The game uses 1 unit = 1 metre. Streets are 9 m wide, blocks 30 m. Real blocks are longer, so I will **compress** while keeping the order of buildings and the character of each side of the street.
- 5 to 8 buildings per block is the sweet spot for phones. If a block has more, mark the ones that matter most.
- I will not invent facts about real places. If something on your drawing conflicts with what I think I see, I will ask instead of guessing.
- Real business names and logos: use fictional names inspired by the real ones in the game, unless the owner agrees.
- Murals: the real ones belong to their artists. We make original murals in the tradition, tied to the Layers story, ideally with local artists' blessing.
